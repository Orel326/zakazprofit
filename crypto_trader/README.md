# Crypto Trader — этап 1

Изолированный Python-модуль сбора публичных рыночных данных Binance Spot для BTC/USDT и ETH/USDT. Не связан с веб-калькулятором ЗаказПрофит и не содержит торговых операций.

## Возможности

- Получение закрытых OHLCV-свечей через публичный API Binance Spot (ccxt).
- Проверка структуры, числовых значений, OHLC-границ, временного порядка, дубликатов и пропусков.
- Сохранение свечей в SQLite с уникальным ключом биржа/символ/таймфрейм/время.
- Повторный запуск безопасен: существующие свечи обновляются по ключу.
- API-ключи не требуются. Торговых функций в этом этапе нет.

## Запуск

Требуется Python 3.11+.

```bash
cd crypto_trader
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env  # Windows PowerShell: Copy-Item .env.example .env
python -m crypto_trader.cli --days 30 --timeframe 1h
pytest
```

Данные по умолчанию сохраняются в `data/market_data.sqlite3`. Путь можно изменить через `DATABASE_PATH`.

## Команда

```bash
python -m crypto_trader.cli --symbols BTC/USDT ETH/USDT --days 30 --timeframe 1h
```

Поддерживаемые интервалы Binance/ccxt: `1m`, `5m`, `15m`, `1h`, `4h`, `1d`. Для первичного запуска рекомендуем `1h`.

## Переменные окружения

См. `.env.example`. Настройки не включают ключи биржи. Не добавляйте секреты в Git.

## Архитектура

- `config.py` — конфигурация из переменных окружения.
- `exchange.py` — публичный клиент и загрузка закрытых свечей.
- `quality.py` — проверки данных.
- `storage.py` — SQLite.
- `cli.py` — запуск сбора.
- `tests/` — автоматические тесты.

На следующем этапе модуль можно подключить к сервису расписания/воркеру, журналу событий и аналитическим агентам. Сейчас это только сбор данных, без рекомендаций и сделок.
